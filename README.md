# BondRisk DV01

Учебный веб-модуль по кейсу 3 ознакомительной практики. Он оценивает, на сколько рублей приблизительно изменится стоимость введённых позиций в облигациях, если ставка вырастет на один базисный пункт. Сделки гипотетические. Например, рост ставки с 10% до 10,01% соответствует шоку +1 б.п.

## Запуск в PyCharm

1. Откройте папку проекта и выберите Python 3.9 или новее. Если в папке уже создано окружение, выберите `.venv/Scripts/python.exe`.
2. Для новой копии проекта выполните команды ниже в PowerShell из корневой папки. Если `.venv` уже есть и зависимости установлены, достаточно последней команды. Тот же запуск можно сделать кнопкой Run для `main.py`.
3. Откройте `http://127.0.0.1:8080` в браузере. При запуске создаётся `instance/catalog.sqlite3` с тремя тестовыми бумагами. Интернет для расчёта на этих данных не требуется.

```powershell
py -3.9 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe main.py
```

## Расчёт

При вводе количества текущая стоимость в рублях равна `количество × номинал × (котировка в процентах / 100) × курс`. Номинал берётся в валюте инструмента, курс задан в рублях за единицу валюты. Для рублёвых бумаг курс равен 1. В режиме прямого ввода используется введённая стоимость в рублях.

`DV01 = стоимость × (−модифицированная дюрация × 0,0001 + 0,5 × выпуклость × 0,0001²)`.

Для плавающего купона дюрация равна `1 / число выплат в год`, а выпуклость равна 0. Для нескольких сделок итог считается как сумма знаковых DV01. Это рабочее допущение до подтверждения экспертом. Сервер считает через `Decimal`, браузер отображает рубли с округлением до копеек.

## Архитектура и API

```text
Браузер → Flask API → SQLite → расчёт на Python → Flask API → браузер
```

- `main.py` настраивает Flask, маршруты страниц и запуск через Waitress.
- `templates/` содержит страницы расчёта, справочника и методики, а также общий шаблон. Стили и скрипт калькулятора лежат в `static/css/` и `static/js/`.
- Тестовые бумаги заданы в `bond_risk/data/demo.json`. При первом запуске Python загружает их в SQLite.
- `bond_risk/api.py` содержит HTTP-маршруты для расчёта и справочника.
- `bond_risk/risk.py` проверяет позиции и рассчитывает DV01. `catalog.py` управляет таблицами `instruments` и `snapshots` в SQLite. Справочники `demo` и `market` разделены.
- `bond_risk/market.py` проверяет CSV и загружает курсы Банка России.
- `GET /api/instruments` отдаёт режим, метаданные рыночного снимка и список инструментов. `GET /healthz` проверяет доступность БД.
- `POST /api/calculate` принимает `{"positions":[{"isin":"RUDEMO000016","mode":"quantity","amount":"10"}]}`. Для прямой стоимости используется режим `rub`. Сервер возвращает строки расчёта и поле `total`. Десятичные значения передаются строками, чтобы сохранить точность. Для рыночного режима в тело запроса добавляется `revision` из `snapshot`. Ошибка ввода возвращает HTTP 400, устаревший снимок — HTTP 409.

## Рыночные данные

`docs/market-template.csv` — пустой шаблон для загрузки реальных облигаций. Для демо достаточно встроенных тестовых бумаг. Для рыночного режима сохраните копию шаблона как `market.csv` и заполните по одной строке на облигацию, используя данные на одну дату. Для `fixed` нужны модифицированная дюрация и выпуклость, для `floating` — частота купонных выплат. В `source` укажите, откуда взяты рыночные параметры. Котировка вводится в процентах от номинала, например `95`.

```powershell
.venv\Scripts\python.exe -m flask --app bond_risk import-market .\market.csv --date 2026-11-18
$env:DV01_DATASET = 'market'
.venv\Scripts\python.exe main.py
```

Импорт получает дневные курсы на указанную дату из XML Банка России, делит опубликованное значение на номинал курса и фиксирует фактическую дату курсов. После проверки всех строк снимок записывается в SQLite одной транзакцией. Импортированным снимком можно пользоваться без интернета. Для возврата к тестовым данным запустите проект с `DV01_DATASET=demo` или уберите эту переменную из конфигурации запуска.

Документация поставщиков данных: [Банк России — XML](https://cbr.ru/development/sxml/), [Московская биржа — ISS](https://www.moex.com/a2920). Курсы Банка России загружаются автоматически. Номинал, котировка и параметры риска бумаги поставляются через проверенный CSV. Прямой импорт облигаций из ISS и готовый рыночный CSV пока отсутствуют.

## Дальнейшая сдача

Для показа 3 нужны экран на тестовых данных и ТЗ на фронтенд. К финальной защите кейс дополнительно требует публичную ссылку на веб-сервис, Git-репозиторий с историей, документацию и презентацию на 10–15 слайдов. Для демонстрации серверного API и SQLite нужен хостинг с Python.

Для развёртывания Python-версии указываются зависимости из `requirements.txt`, команда `python main.py`, `DV01_HOST=0.0.0.0` и порт хостинга в `PORT`. Если нужен рыночный режим, используется постоянный диск для файла из `DV01_DATABASE`. Автозапуск создаёт тестовый справочник.
